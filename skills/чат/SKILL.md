# Счётчик токенов чата

Эта команда (`/чат`, алиасы `/ctx`, `/chat`, `/tokens`) перехватывается локальным `PreInvocation`-хуком `chat-context-command` без обращения к модели (0 токенов). Если хук не сработал, прочитай последний `input_tokens + cache_read_tokens` из `transcript.jsonl` текущего чата и ответь одной короткой строкой с количеством токенов.
